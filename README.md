## 🚀 Featured Engineering Case Studies

### 1. [HomeCertifi — Multi-Tenant AI Property Inspection Platform](https://github.com/Wajahat-Ali-Khan)
* **Architecture:** FastAPI, Weaviate Vector DB, AWS Bedrock (Claude 3.5 Sonnet / Haiku), PostgreSQL, Stripe Webhook Engine, AWS S3/CloudFront.
* **Key Achievements:**
  - Designed multi-tenant SaaS architecture with complete tenant data isolation, schema segregation, and role-based access control (RBAC).
  - Built confidence-gated dual-model RAG pipeline achieving **75% LLM cost reduction** by routing deterministic parsing to lightweight models and reserving Claude Sonnet for complex edge-cases.
  - Implemented event-driven Stripe subscription lifecycle handling tiered quotas, upgrade proration, and automated invoice reconciliation.

### 2. [Enterprise Legal & Regulatory RAG Assistant](https://github.com/Wajahat-Ali-Khan)
* **Architecture:** Python, Azure OpenAI (GPT-4o), Azure AI Search (Hybrid + Semantic Reranking), LangChain, Redis Cache.
* **Key Achievements:**
  - Engineered production RAG pipeline ingesting 100k+ multi-format legal documents with citation-backed precision answers.
  - Reduced query response times from 3.8s to 820ms using multi-tiered Redis semantic prompt caching and asynchronous chunk streaming.
  - Full GDPR-compliant data sanitization middleware with automated PII masking before embedding generation.

### 3. [High-Scale Clinical AI & Healthcare Multi-Agent System](https://github.com/Wajahat-Ali-Khan)
* **Architecture:** FastAPI, Celery, Redis Streams, AWS Lambda, PostgreSQL, Milvus Vector DB.
* **Key Achievements:**
  - Architected asynchronous multi-agent orchestration for clinical note synthesis and automated diagnosis cross-verification.
  - Sustained 10,000+ concurrent requests during peak hours with sub-50ms API response latency using asynchronous connection pooling.

### 4. [UdhaarBook — High-Concurrency Fintech Wallet & Analytics Pipeline](https://github.com/Wajahat-Ali-Khan)
* **Architecture:** Django, Django REST Framework, PostgreSQL, Celery, Redis, GCP BigQuery, Elasticsearch.
* **Key Achievements:**
  - Built custom double-entry ACID-compliant wallet balances with row-level database locking, preventing race conditions under high transaction loads.
  - Developed automated GCP BigQuery ETL pipelines aggregating $5M+/month transactional data into real-time executive risk dashboards.
